# 第1回 解答

## 演習

- 使用モデル：`gemini-3.5-flash-lite`
- 一般的な質問「LoRAとは何ですか？」への回答（要約）：
  - 「Low-Rank Adaptationの略で、基盤モデルの重みを固定し、小規模な追加パラメータを学習して効率よく適応させる技術」と回答した。基本的な意味は概ね正しい。
- 講座に固有の質問「AIE2026の講座の宿題にある『3レベル』とは何ですか？」へのモデルの回答（要約）：
  - 講座名から一般的な学習課題だと推測し、「レベル1＝基礎・ベーシック、レベル2＝応用・スタンダード、レベル3＝発展・アドバンス」と説明した。
  - さらに「基本はレベル2を目指すのがおすすめ」と述べたが、実際の課題の具体的な内容は説明できなかった。
- 用語集の正しい意味と比べて気づいたこと：
  - `data/glossary.json` の `homework-levels` は「基礎（講義内容の確認）」「実装（自分でコードを書く）」「発展（調査や試行）」であり、**どれか1つを実施すれば完了**、原則として採点はしない、と定義している。
  - 今回の第1回の具体的な課題は、基礎＝モデルや生成設定を変えた回答比較、実装＝会話履歴を保つ改修、発展＝応答時間・トークン数の測定と比較である。
  - モデルはレベル名の一部を一致させたものの、「応用」という実際と異なる名称や一般論から推測した課題例を挙げた。講座を知らない状態で具体的な情報をもっともらしく補うことがある、と分かった。
- 表示できたトークン数（入力 / 出力）：
  - 会話モードで実測した結果、1回目は入力10・出力30、2回目は入力51・出力17トークンだった。
